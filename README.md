# 🚀 Smart Task Manager

A full-stack productivity web application to manage tasks, track progress, and improve daily productivity.

---

## ✨ Features

- 📅 Task management (Today / Upcoming / Past)
- 🧠 Productivity tracking & analytics
- 🔥 Daily streak system
- 👥 Team task collaboration
- 🗂 Calendar integration
- 🌙 Dark mode UI
- 🔐 Authentication system (Login/Register)

---

## 🛠 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Vite

### Backend
- Node.js
- Express.js
- MongoDB

---

## ⚙️ Setup Instructions

### 1. Clone the repository

```bash
git clone https://github.com/your-username/smart-task-manager.git

2. Install dependencies

Backend:

cd backend
npm install

Frontend:

cd frontend
npm install

Create .env file (backend)
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret_key
PORT=5000
4. Run the project

Backend:

npm start

Frontend:

npm run dev
